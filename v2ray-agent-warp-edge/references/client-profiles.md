# Client profile rules

## Common WSS fields

For an orange-cloud WSS hostname, the address, TLS server name, and WebSocket Host normally use the WSS hostname. The port is the public HTTPS port exposed by the front door, usually `443`. The effective path must match the Xray fallback exactly and must contain one leading slash.

## VLESS WS

Use the VLESS UUID and the VLESS WS path. A representative profile shape is:

```text
vless://UUID@WSS_HOST:443?encryption=none&security=tls&type=ws&host=WSS_HOST&sni=WSS_HOST&fp=chrome&path=%2Fexample-vless-ws-warp#VLESS-WS-WARP
```

The example uses `/example-vless-ws-warp` only as a placeholder. Substitute the actual VLESS WARP path. URI encoding `%2F` is only for the URI representation; the client runtime must send `/actual-path`, not `/%2Factual-path` or `//actual-path`.

## VMess WS

VMess links contain a Base64-encoded compact UTF-8 JSON object. Inside the decoded JSON, use the literal path beginning with `/`; do not store `%2F` there. Use the VMess UUID and VMess WS path. A VMess profile must not reuse a VLESS path merely because both transports use WebSocket. Apply the requested display name to the decoded JSON `ps` field before Base64 encoding; changing text after `vmess://` encoding has no effect.

## REALITY

Use the generated public key, short ID, flow, fingerprint, transport, and camouflage server name exactly as emitted by the current agent. REALITY does not need the WSS certificate, but it still needs a valid public/private key configuration and a reachable DNS-only endpoint.

## Hysteria2

Use the Hysteria2 password, UDP port, SNI, ALPN, and bandwidth values generated by the agent. Keep certificate verification enabled. The hostname must be DNS-only for a normal Internet Hysteria2 deployment.

## WARP verification

The client profile does not contain a WARP key. WARP is selected by the server's inbound tag. To prove that a WARP clone works, use a trace endpoint that reports both the egress IP and `warp=on`. Comparing only the VPS's own `curl` output tests the server's direct route, not the proxy client route.

If the WARP outbound is IPv4-only, force the trace request to IPv4. Otherwise a client or trace hostname may prefer IPv6, producing a timeout or a direct IPv6 result that does not test the configured WARP path.

When the user asks for multiple import links separated by `|`, emit one uninterrupted line with exactly one `|` between links. Preserve the installation's established display-name convention, including case, hyphens, and underscores; for example, read existing subscription labels before inventing names.
